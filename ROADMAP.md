# Practice roadmap

Work through these topics at a comfortable pace. This is a plan, not a record of completed work.

| Stage | Focus | Practice goal |
| --- | --- | --- |
| 1 | Arrays, loops, and Big O | Trace loops, choose examples, write a simple approach, and explain time and extra space. |
| 2 | Sets and dictionaries | Learn membership checks, uniqueness, counting, and key/value lookup; compare approaches after an initial attempt. |
| 3 | Two pointers and binary search | Reason about indices, sorted inputs, boundaries, and loop termination. |
| 4 | Stacks and queues | Understand processing order and choose a suitable structure. |
| 5 | Linked lists | Trace references and reason about empty, single-node, and multi-node cases. |
| 6 | Recursion and trees | Identify base cases, trace calls, and explore basic tree traversals. |

## First milestone

Start with [Contains Duplicate](exercises/001-contains-duplicate/README.md) in C#. Make and test an independent first attempt before comparing it with a `HashSet` approach.

For each exercise, keep notes on examples, approach, tests, complexity, hints, lessons, and a revisit plan. Move forward when the reasoning is explainable, rather than chasing a fixed problem count.
